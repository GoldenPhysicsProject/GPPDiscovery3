# Supersymmetric decomposition of the one-loop pure-Yang--Mills rational sector

Codex/GPT discovery track, 2026-08-25.

## State-counting identity

For a color-ordered one-loop amplitude with four-dimensional external gluons, decompose loop-state content into the standard supersymmetric multiplets:

- one N=4 vector multiplet = one gluon + four Weyl fermions + three complex scalars;
- one N=1 chiral multiplet = one Weyl fermion + one complex scalar;
- one complex adjoint scalar = one complex scalar.

Therefore the state content satisfies the exact linear identity

\[
\boxed{
A^{[1]}
= A^{\mathcal N=4}
 -4 A^{\mathcal N=1\,\mathrm{chiral}}
 + A^{[0]},
}
\]

because the fermion multiplicity is `4-4=0` and the complex-scalar multiplicity is
`3-4+1=0`, leaving one gluon state sector.

This is a loop-state decomposition, not a kinematic approximation.

## Consequence for rational terms

At one loop in massless gauge theory, the N=4 and N=1 supersymmetric amplitudes are four-dimensional cut-constructible: their purely rational remainders vanish after the usual scalar-integral basis reduction. Hence, in the standard four-dimensional-helicity/FDH organization,

\[
\boxed{
R\bigl[A^{[1]}\bigr]
=R\bigl[A^{[0]}\bigr].
}
\]

Thus the rational part of the pure-gluon one-loop amplitude does **not** require the complete nonzero-`mu` gluon state sum if the only target is the rational remainder. It can be reconstructed from the complex-adjoint-scalar generalized cuts.

For the `1^-2^-3^+4^+` channel already isolated in this workbench, the scalar box boundary term is

\[
C_s^{[0]}\big|_{\mu^4}
=-\mu^4
\frac{\langle12\rangle[34]}
     {[12]\langle34\rangle}
\frac1{D_LD_R},
\]

so the corresponding rational box information is already in the correct state sector for the pure-YM rational remainder.

## What this does and does not remove

This reduction removes one obstruction but not all of them.

It removes the need to compute the entire `D_s=4, mu!=0` gluon numerator merely to obtain the one-loop rational term.

It does **not** remove the lower-topology scalar sectors. In a renormalizable theory, rational reconstruction also requires the `mu^2` triangle and bubble coefficients (and any subtraction terms generated by the chosen integral reduction). Therefore the remaining amplitude task is now sharply reduced to

\[
\boxed{
\text{complex-scalar }\mu^4\text{ boxes}
\; +\;
\text{complex-scalar }\mu^2\text{ triangles/bubbles}.
}
\]

The box part has already been angularly reduced on the fixed-radius celestial `S^2`; the triangle and bubble scalar cuts are the next honest generalized-cut targets.

## Scheme boundary

The identity above is the standard supersymmetric decomposition used in the four-dimensional-helicity/FDH organization of one-loop amplitudes. Dimensional-regularization scheme conversion can add finite shifts when changing the spin dimension `D_s` (for example to the 't Hooft--Veltman scheme). Those scheme-conversion terms must be applied separately; they are not contained in the state-counting identity itself.

This note therefore narrows the rational-sector problem but does not claim a scheme-independent integrated pure-Yang--Mills amplitude yet.
